# 명명 체계 — 단어/용어 사전과 물리명 자동생성

## 목적

행안부 표준 체계와 호환되는 **단어–용어–도메인 3단 명명 체계**로 논리명/물리명을 일관되게 관리한다. 검증은 경고 수준으로 하여 작업 흐름을 막지 않는다.

## 사용자 시나리오

- 프로젝트 시작 시 서비스가 제공하는 행안부 표준 단어사전을 프로젝트로 가져온다.
- 컬럼 논리명에 "회원번호"를 입력하면 물리명 `MBR_NO`와 도메인 "번호"가 자동 제안된다.
- 사전에 없는 단어 "쿠폰"을 쓰면 경고 배지가 뜨고, 그 자리에서 약어 `CPN`으로 단어를 등록한다.
- 산출물 제출 전, 미등록 단어 목록 화면에서 남은 경고를 일괄 정리한다.

## 기능 상세

### 3단 체계

| 단계 | 예 | 역할 |
|---|---|---|
| Word(단어) | 회원 = `MBR`, 번호 = `NO` | 명명의 최소 단위. 물리 약어의 원천 |
| Term(용어) | 회원번호 = [회원]+[번호] → `MBR_NO`, 기본 도메인 "번호" | 컬럼 논리명과 1:1로 대응하는 표준 명칭 |
| Domain(도메인) | 번호 → 방언별 물리 타입 | 타입의 표준 정의(→ [14-domain](14-domain.md)) |

### 프로젝트 명명 규칙 설정

- 물리명 케이스: `UPPER_SNAKE`(기본) / `lower_snake`.
- 단어 구분자: `_`(기본) / 없음.
- 물리명 최대 길이 경고 기준(기본 30바이트 — Oracle 구버전 호환).
- 대상 DB 방언의 예약어 충돌 경고.

### 물리명 자동생성 플로우

컬럼(또는 테이블) 논리명 입력 시:

1. **용어 완전 일치** — 용어사전에 논리명이 있으면 그 물리명과 기본 도메인을 제안.
2. **단어 분해 조합** — 없으면 논리명을 단어사전 기준 최장 일치 우선으로 분해(예: "회원상태코드" → 회원+상태+코드)하고, 각 단어의 약어를 구분자로 조합해 물리명 생성. 이때 "용어로 등록" 버튼으로 결과를 용어사전에 축적할 수 있다.
3. **분해 실패** — 사전에 없는 단어가 포함되면 해당 부분을 경고 배지로 표시. 물리명은 사용자가 직접 입력하고, 인라인으로 단어 등록을 유도한다.
4. 자동 제안 후에도 물리명은 항상 수동 수정 가능. 사전과 불일치하면 경고 배지만 표시한다(저장 허용).

### 경고 체계

- 경고 종류: 미등록 단어 포함, 용어-물리명 불일치, 최대 길이 초과, 예약어 사용, 물리명 중복(이건 오류 수준으로 강조하되 저장은 허용).
- 노출 위치: 캔버스 노드 배지, 편집 패널, 프로젝트 전체 "명명 검사" 화면(경고 모아보기, 항목별 바로가기).

### 사전 관리 화면

- 단어/용어/도메인 탭별 목록: 검색, 추가/수정/삭제, Excel 일괄 업로드(→ [17-import-export](17-import-export.md)).
- **사용처 조회**: 단어·용어가 어떤 테이블/컬럼에서 쓰이는지 역참조 목록.
- 용어 수정 시 사용 중인 컬럼에 변경 반영 여부를 선택(일괄 반영 / 유지).
- **미등록 단어 모아보기**: 경고 상태인 단어 후보를 모아 일괄 등록.

### 공용 사전 가져오기와 재동기화

[01-concepts](01-concepts.md#공용-리소스-패턴-복사fork--재동기화)의 공통 패턴을 따른다.

- 서비스 전역 리소스: 행안부 표준 단어사전 등 공공 표준을 Schemantic이 큐레이션해 제공.
- 조직 리소스: 조직 표준 사전을 만들어 여러 프로젝트에서 재사용.
- 프로젝트에서 가져온 뒤 자유 수정, 원본 갱신 시 수동 재동기화(충돌 항목별 선택).
