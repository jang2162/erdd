# 가져오기 / 내보내기

## 목적

설계 결과를 실행 가능한 DDL, 제출 가능한 Excel 산출물, 공유 가능한 이미지로 내보내고, 기존 자산(DDL, Excel 사전)을 가져와 초기 구축 비용을 줄인다.

## 사용자 시나리오

- 개발 착수 시 PostgreSQL DDL을 내보내 마이그레이션 도구에 넣는다.
- 감리 대응으로 테이블정의서·단어사전·도메인정의서 Excel을 내보내 제출한다.
- 기존 운영 DB의 DDL을 붙여넣어 역설계로 ERD를 만들고, 사전을 붙여 논리명을 복원한다.

## 기능 상세

### DDL 내보내기

- 대상 방언: PostgreSQL / MySQL·MariaDB / Oracle / MSSQL.
- 출력 내용: CREATE TABLE(컬럼 타입·NOT NULL·기본값·자동증가), PK, FK, 인덱스, 테이블·컬럼 코멘트(논리명+설명, 방언별 문법), 도메인 허용값의 CHECK 제약.
- 타입 해석: 도메인 지정 컬럼은 도메인의 방언별 매핑, 직접 타입 컬럼은 기본 변환 표 적용(→ [14-domain](14-domain.md)). 해석 불가 타입은 입력 원문을 그대로 출력.
- 범위 선택: 전체 / 그룹 단위 / 선택 테이블.

### Excel 산출물 내보내기

하나의 워크북 또는 개별 파일로 내보내기. 시트 구성:

| 시트 | 내용 |
|---|---|
| 테이블 목록 | 그룹, 논리명, 물리명, 설명, 테이블 커스텀 항목 |
| 테이블정의서 | 테이블별 컬럼 상세: 논리명, 물리명, 도메인, 타입, PK/NN, 기본값, 설명, 컬럼 커스텀 항목 |
| 단어사전 | 논리명, 약어, 영문명, 설명 |
| 용어사전 | 용어, 구성 단어, 물리명, 기본 도메인, 설명 |
| 도메인정의서 | 이름, 분류, 논리 타입, 방언별 타입, 기본값, 허용값 |
| 변경분 정의서 | 스냅샷 diff 결과(선택 시) |

- 커스텀 항목은 정의 순서대로 추가 컬럼으로 포함된다.
- 발주처별 양식 템플릿 커스터마이징은 이번 범위에서 제외(로드맵 "추후 검토").

### 이미지 내보내기

- PNG / SVG. 전체 뷰 또는 그룹 뷰 단위. 현재 보기 모드(논리명/물리명/혼합) 반영.

### DDL 가져오기 (역설계)

- DDL 텍스트 붙여넣기 또는 파일 업로드 → 파싱해 테이블/컬럼/PK/FK/인덱스 생성. 방언 자동 감지 + 수동 선택.
- 물리명→논리명 복원: 프로젝트 단어/용어사전으로 물리명을 역매칭해 논리명을 제안(예: `MBR_NO` → 회원번호). 매칭 실패분은 물리명을 논리명으로 두고 경고 표시.
- 가져온 테이블은 자동 배치 후 수동 정리.

### Excel 사전 업로드

- 단어/용어/도메인 사전을 정해진 양식의 Excel로 일괄 등록. 중복(기존 항목과 같은 논리명)은 건너뛰기/덮어쓰기 선택.
- 업로드 양식 파일 다운로드 제공.

## 다른 영역과의 연계

- **Phase 2**: Excel 산출물 내보내기, Excel 사전 업로드, 변경분 정의서(diff는 Phase 3이므로 이 시트만 Phase 3).
- **Phase 4**: DDL 가져오기(역설계).
