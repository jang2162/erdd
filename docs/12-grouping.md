# 테이블 그룹핑

## 목적

업무 영역(예: 회원, 주문, 정산) 단위로 테이블을 묶어, 큰 모델을 영역별로 나눠 보고 영역별로 따로 배치·관리한다.

## 사용자 시나리오

- 설계자가 "회원", "주문", "정산" 그룹을 만들고 테이블을 배정한다. 전체 뷰에서 그룹별 색상 영역으로 구분되어 보인다.
- 주문 도메인 리뷰 회의에서 "주문" 그룹 뷰만 열어, 그 그룹 테이블만으로 보기 좋게 배치한 화면을 공유한다.
- 그룹별로 테이블정의서를 나눠 내보내 업무 담당자별로 전달한다.

## 기능 상세

### 그룹 관리

- 그룹 생성: 이름, 색상, 설명. 테이블은 **최대 1개 그룹**에 속한다(미배정 허용).
- 배정 방법: 편집 패널에서 선택, 또는 전체 뷰에서 테이블 다중 선택 후 일괄 배정.
- 좌측 테이블 목록 트리가 그룹별로 묶여 표시되고, 미배정 테이블은 "미분류"로 모인다.

### 전체 뷰

- 프로젝트의 모든 테이블을 한 캔버스에 표시. 그룹은 색상 영역(배경 박스)으로 표현.
- 그룹 영역을 드래그하면 소속 테이블이 함께 이동.

### 그룹 뷰 (독립 배치)

- 그룹을 선택해 전환하면 해당 그룹 테이블만 표시된다.
- 그룹 뷰의 배치 좌표는 **전체 뷰와 독립**이다. 그룹 뷰에서 재배치해도 전체 뷰 배치는 유지된다.
- **외부 참조 테이블**: 그룹 내 테이블과 관계가 있는 다른 그룹의 테이블은 간략 노드(헤더만, 반투명)로 표시해 관계의 맥락을 보여준다. 클릭하면 해당 그룹 뷰로 이동.

### 그룹 단위 활용

- 검색·필터: 그룹 기준 필터.
- 내보내기: 그룹 단위 이미지/테이블정의서 내보내기(→ [17-import-export](17-import-export.md)).

## 다른 영역과의 연계

- 배치 좌표 모델(전체 뷰 1벌 + 그룹 뷰 1벌)은 [01-concepts](01-concepts.md)의 Table/TableGroup 정의를 따른다.
- 그룹 정보는 CLI 파일 포맷(`groups.yaml`)에 포함(→ [16-cli](16-cli.md)).

## 단계별 범위

- **Phase 1**: 그룹 관리, 전체 뷰 색상 영역, 그룹 뷰(독립 배치, 외부 참조 테이블), 그룹 필터. 그룹 단위 DDL·이미지 내보내기는 Phase 1의 내보내기 기능에 포함.
- **Phase 2**: 그룹 단위 Excel 산출물(테이블정의서) 내보내기.
