# ERD 에디터

## 목적

GUI에서 테이블·컬럼·관계를 직접 편집하는, 제품의 중심 화면. 구조화된 모델이 진실 원천이고 DSL은 두지 않는다(파일 포맷은 CLI 동기화 용도 → [16-cli](16-cli.md)).

## 사용자 시나리오

- 설계자가 캔버스에 테이블을 만들고 컬럼을 채운 뒤 관계선을 드래그로 연결한다.
- 리뷰어가 논리명 보기로 전환해 업무 용어 기준으로 모델을 검토한다.
- 개발자가 특정 테이블을 검색해 이동하고, 컬럼 상세와 인덱스를 확인한다.

## 기능 상세

### 캔버스

- 무한 캔버스, 줌/팬, 미니맵.
- 테이블 노드: 물리명/논리명 헤더 + 컬럼 목록(PK·FK·NN 마커, 타입/도메인). 노드 접기(헤더만 보기) 지원.
- 관계선: 자식 테이블의 헤더 또는 컬럼에서 부모 테이블로 드래그하여 생성(동작은 아래 "관계 편집 시맨틱"). 1:1/1:N, 식별(실선)/비식별(점선) 표기. 까마귀발(crow's foot) 표기법.
- Note(메모): 캔버스 어디든 배치, 색상 지정.
- 자동 정렬: 선택 테이블 또는 전체를 관계 기반으로 자동 배치.
- 다중 선택, 복사/붙여넣기(테이블 단위), 실행 취소/재실행.

### 편집 패널 (사이드 패널)

- 테이블 선택 시: 논리명/물리명, 설명, 소속 그룹, 커스텀 항목 값, 컬럼 목록 편집.
- 컬럼 편집: 논리명 입력 → 물리명·도메인 자동 제안(→ [13-naming](13-naming.md)), 도메인 선택 또는 직접 타입 입력(→ [14-domain](14-domain.md)), PK/NN/기본값, 순서 드래그 변경.
- 인덱스 탭: 구성 컬럼(순서·정렬 방향), 유니크 여부, 이름.
- 관계 선택 시: 카디널리티, 식별/비식별, 참조 컬럼 매핑, 관계명.

### 관계 편집 시맨틱

**생성 (하이브리드).**

- 테이블 **헤더**에서 부모로 드래그 → 부모 PK 컬럼(복합이면 전부)을 자식에 FK 컬럼으로 자동 생성. 물리명·논리명·타입/도메인을 복제하고 NOT NULL로 생성(자유 변경 가능). 물리명이 자식에 이미 있으면 숫자 접미(`_2`)를 붙이고 경고 배지로 정리를 유도.
- 기존 **컬럼**에서 부모로 드래그 → 그 컬럼을 FK로 매핑만 한다. 부모가 복합 PK면 관계 편집 패널에서 나머지 컬럼을 매핑(기존 컬럼 지정 또는 자동 생성 혼합).
- 참조 컬럼 타입 불일치는 경고 배지(저장 허용).

**식별/비식별 전환은 자동 처리.** 식별로 설정하면 FK 컬럼들이 자식 PK에 편입(기존 PK 뒤 순서), 비식별로 전환하면 PK에서 제외된다. 식별 관계는 자식 PK를 바꾸므로 손자 관계에 연쇄된다 → 아래 "확인 후 일괄 반영"으로 처리.

**부모 PK 변경 — 확인 후 일괄 반영** (도메인 일괄 반영과 동일 UX, → [14-domain](14-domain.md)).

- 부모 PK 컬럼의 타입/도메인 변경 시: 영향받는 자식 FK 컬럼 목록을 보여주고, 확인하면 Revision 1건으로 일괄 반영, 거부하면 타입 불일치 경고 배지만 남긴다. 자동 강제 전파는 하지 않는다.
- 부모 PK에 컬럼 추가/제거 시: 해당 관계에 "매핑 불완전" 경고를 표시하고 관계 패널에서 수동 정리한다.

**삭제 처리.** 부모 테이블/PK 컬럼 삭제 시 관계는 삭제되지만 **자식 FK 컬럼은 일반 컬럼으로 남긴다**(설계 정보 보존). 매핑에 쓰인 자식 컬럼을 삭제하면 매핑에서 제거되고, 매핑이 비면 관계도 삭제된다(확인 후).

**허용 범위.** 자기참조 관계 허용(예: 부서→상위부서), 동일 테이블 쌍의 다중 관계 허용(관계명으로 구분).
**N:M 카디널리티는 모델에 없다**(`cardinality` 는 `1:1` / `1:N` 둘뿐이다). 대신 관계 패널의
**"교차 테이블로 풀기"** 버튼이 1:N 관계 하나를 **교차 테이블 1개 + 식별 1:N 관계 2개**로 바꾼다
(2026-08-09 완료 → [90-roadmap](90-roadmap.md)). 결과물이 보통 테이블과 관계일 뿐이라
DDL·diff·병합·파일 포맷·CLI 가 새로 알아야 할 것이 없다.

### 보기 모드

- **논리명 보기 / 물리명 보기 / 혼합 보기**(논리명+물리명 병기) 전환. 캔버스 노드와 편집 패널에 일괄 적용.
- 그룹 뷰 전환(→ [12-grouping](12-grouping.md)).

### 검색·탐색

- 테이블/컬럼 이름 검색(논리명·물리명 모두), 결과 클릭 시 해당 노드로 이동·강조.
- 좌측에 테이블 목록 트리(그룹별 묶음) 표시.

### 유효성 표시

- 명명 경고(미등록 단어/용어), 물리명 중복, 관계 컬럼 타입 불일치 등을 노드·패널에 경고 배지로 표시. 저장을 막지 않는다.

## 다른 영역과의 연계

- 편집 이벤트는 모두 Revision으로 기록되고 실시간 협업의 전파 단위가 된다(→ [11-collaboration](11-collaboration.md)).
- 논리명 입력 시 명명 체계와 상호작용(→ [13-naming](13-naming.md)).
- 내보내기 메뉴(DDL/이미지/Excel)는 에디터 상단에서 진입(→ [17-import-export](17-import-export.md)).

## 단계별 범위

- **Phase 1**: 위 기능 전체(단독 편집 기준, 컬럼 타입은 직접 입력). 실행 취소/재실행 포함.
- **Phase 2**: 편집 패널에 명명 자동 제안·경고 배지, 도메인 선택, 커스텀 항목 입력이 각 기능 도입과 함께 추가된다.
- **Phase 3**: 실시간 동시편집 결합(presence, 타인 변경 즉시 반영).
