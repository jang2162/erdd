# 커스텀 항목

## 목적

프로젝트마다 다른 관리 항목(암호화여부, 개인정보여부, 비고 등)을 테이블/컬럼에 추가 정의해, 산출물과 동기화 파일까지 일관되게 흐르게 한다.

## 사용자 시나리오

- 공공 프로젝트에서 컬럼용 커스텀 항목 "개인정보여부(불리언, 필수)"와 "암호화방식(선택형: 없음/AES256/SHA256)"을 정의한다.
- 컬럼 편집 패널에 두 항목이 나타나고, 테이블정의서 Excel에도 컬럼으로 포함된다.
- 조직에서 표준 항목 템플릿을 만들어 신규 프로젝트마다 가져온다.

## 기능 상세

### 정의

| 속성 | 설명 |
|---|---|
| 이름 | 예: 개인정보여부 |
| 적용 대상 | 테이블 / 컬럼 |
| 타입 | 텍스트 / 불리언 / 선택형(선택지 목록 정의) |
| 필수 여부 | 필수인데 미입력이면 경고(저장은 허용 — 명명 경고와 동일 정책) |
| 기본값 | 선택 |
| 순서 | 편집 패널·산출물에서의 표시 순서 |

### 값 입력과 노출

- 편집 패널의 테이블/컬럼 영역에 정의 순서대로 표시.
- 노출 범위: 편집 패널, Excel 산출물(정의서의 추가 컬럼), CLI 파일 포맷(`custom` 필드), 스냅샷 diff(값 변경 추적).
- 캔버스 노드에는 표시하지 않는다(정보 과밀 방지).

### 정의 변경 처리

- 항목 삭제 시: 기존 입력 값도 함께 삭제됨을 경고 후 진행.
- 타입 변경은 불허(삭제 후 재생성). 선택형 선택지 추가는 자유, 삭제는 사용 중인 값이 있으면 경고.

### 조직 템플릿

[01-concepts](01-concepts.md#공용-리소스-패턴-복사fork--재동기화)의 공통 패턴을 따른다. 조직 수준에서 커스텀 항목 템플릿을 정의하고 프로젝트로 가져온다.
