# 협업과 버전 관리

## 목적

여러 명이 같은 모델을 동시에 편집하고, 모든 변경을 추적하며, 의미 있는 시점을 스냅샷으로 고정·비교·복원한다.

## 사용자 시나리오

- 설계자 두 명이 같은 ERD를 열어 각자 다른 그룹의 테이블을 동시에 편집한다. 서로의 변경이 즉시 보인다.
- 오픈 배포 시점에 "v1.0" 스냅샷을 만들고, 이후 변경분을 v1.0과 diff로 확인해 변경분 정의서를 만든다.
- 잘못된 대량 수정을 발견하고 어제 시점 스냅샷으로 복원한다.

## 기능 상세

### 실시간 동시편집

- 프로젝트를 연 사용자들이 같은 편집 세션을 공유한다. 참여자 아바타 표시(presence).
- 다른 사용자가 선택·편집 중인 객체에 사용자 색상 하이라이트 표시.
- 변경 전파 단위는 **속성 단위**(예: 컬럼 하나의 논리명). 충돌 정책:
  - 같은 속성 동시 수정 → last-write-wins. 밀린 쪽에 알림 토스트.
  - 삭제 vs 수정 충돌 → 삭제 우선, 수정하던 사용자에게 알림.
- 오프라인/재접속 시 서버 상태 기준으로 재수화(rehydrate). 로컬 미전송 변경은 재적용 시도 후 실패분 알림.

### 자동 이력 (Revision)

- 모든 편집 작업을 Revision으로 기록: 작업자, 시각, 작업 유형(생성/수정/삭제/이동), 대상 객체, 변경 내용(before/after).
- 이력 화면: 시간순 목록, 작업자·객체·유형 필터, 항목 클릭 시 변경 내용 상세.
- 배치 좌표 이동 같은 저정보 변경은 묶음 처리(연속 이동을 1건으로 합침)해 노이즈를 줄인다.

### 명명 스냅샷 (Snapshot)

- 현재 시점(정확히는 현재 Revision)에 이름·설명을 붙여 고정. 예: "v1.0 오픈", "감리 제출본".
- 스냅샷 목록에서 조회 전용으로 열람 가능.
- **복원**: 스냅샷 시점 상태로 프로젝트를 되돌린다. 복원 자체도 Revision으로 기록되어 다시 되돌릴 수 있다.

### diff

- 스냅샷 ↔ 스냅샷, 스냅샷 ↔ 현재 비교.
- 결과는 객체 유형별 목록: 추가/삭제/변경된 테이블·컬럼·관계·인덱스, 변경 속성의 before/after. 사전(단어/용어/도메인) 변경도 포함.
- diff 결과를 Excel(변경분 정의서)로 내보내기(→ [17-import-export](17-import-export.md)).

### 권한

[01-concepts](01-concepts.md#권한-모델)의 2단 모델(조직 역할 × 프로젝트 역할 Admin/Editor/Viewer)을 따른다. 스냅샷 생성은 Editor 이상, 복원·삭제는 Admin.

## 다른 영역과의 연계

- Revision은 CLI push 충돌 판정의 기준점(→ [16-cli](16-cli.md)).
- diff의 Excel 내보내기(→ [17-import-export](17-import-export.md)).

## 단계별 범위

- **Phase 1**: Revision 자동 이력, 이력 화면, 명명 스냅샷 생성·열람·복원. 편집은 단독 편집 기준이되, 데이터 계층은 처음부터 이벤트(작업 로그) 기반으로 설계해 실시간 협업의 기반을 만든다.
- **Phase 3**: 실시간 동시편집(presence, 즉시 반영, 충돌 정책), 스냅샷 diff와 변경분 정의서.
