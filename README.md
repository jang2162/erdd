# ERDD

웹에서 ERD를 실시간 협업으로 설계하고, 한국 실무의 명명 체계(단어·용어·도메인 사전)와 산출물까지 관리하며, CLI로 코드베이스와 AI agent에 연결되는 상용 SaaS.

에디터·실시간 협업·명명 체계·CLI·가져오기/내보내기가 구현되어 동작한다.
